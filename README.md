# RevenueForge — Business Automation Concept

A static landing-page prototype exploring possible lead tracking, task automation and reporting.

## Current state
The repository does **not** contain a working automation system, lead-generation engine, backend, API integration, database or analytics.

## Run
Open `index.html` in a browser. No dependencies.

## Stack
HTML, CSS, vanilla JavaScript.

## Next milestone
